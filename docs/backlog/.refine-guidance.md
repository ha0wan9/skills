# Project Board Refinement Guidance

This guidance is distilled from DASH-08 co-review sessions. Keep it small, current, and specific.

- Project Board v0.1 prioritizes deterministic CLI/store/dashboard work only.
- Items are roadmap-eligible only when `maturity: refined` and `disposition: active`.
- Keep `maturity` about requirement quality; use `status` for execution state and `disposition` for trim/defer/wontfix decisions.
- Browser write-back, capture hooks, orchestration, Linear sync, and review-tier are not v0.1 work.
